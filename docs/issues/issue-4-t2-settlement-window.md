# T+2 시간창: 아직 정산 안 된 건을 누락으로 오검출 방지

## 목표
거래 시점 기준 정산 지연(T+2 등)으로 아직 안 들어온 건을, #1 누락 검출이 오검출하지 않게 한다.

## 범위
- 배치 기간/정산 마감 규칙에 "정산 유예" 개념 도입.
- 유예 기간 내 주문은 누락 후보에서 제외.
- 유예는 **달력일 T+2**로 계산(주말·공휴일 무시). 영업일 기준은 #5로 분리.

## 완료 기준
- [ ] 유예 기간 내 미정산 건이 누락으로 안 잡힘
- [ ] 변이 테스트: 경계(유예 직전/직후)
- [ ] 로직을 뒤집으면 해당 테스트만 red
