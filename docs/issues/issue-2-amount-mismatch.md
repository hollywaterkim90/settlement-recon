# 금액 불일치: 명세 합이 원장과 다른 주문 검출

## 목표
명세 줄은 있으나, `(channel, order_id)`별 `settled_amount` 합이 원장 `amount`와 다른 주문을 검출한다.

## 범위
- 배치 스코프 안에서 원장 `amount` vs 명세 합(`SUM`) 비교.
- 부분정산(여러 줄)은 합산해서 비교.
- `BigDecimal` 비교는 `compareTo(... ) == 0` (scale까지 보는 `equals` 금지).

## 완료 기준
- [ ] 합이 부족/초과인 주문을 각각 검출
- [ ] 변이 테스트: 합 경계, 부분정산 합산, 반올림 케이스
- [ ] 로직을 뒤집으면 해당 테스트만 red
