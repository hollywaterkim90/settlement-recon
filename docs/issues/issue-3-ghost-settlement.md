# 유령 정산: 명세엔 있으나 원장에 없는 주문 검출

## 목표
명세에는 있는데 원장에 대응 주문이 없는 줄(유령/오정산)을 검출한다. (#1 누락의 반대 방향)

## 범위
- `settlement_line` 기준으로 `order_ledger`에 `(channel, order_id)`가 없는 줄 = 유령.
- 원장 ↔ 명세에 FK가 없어야 이 케이스가 성립함(설계 근거).

## 완료 기준
- [ ] 원장에 없는 명세 줄 검출

- [ ] 로직을 뒤집으면 해당 테스트만 red
