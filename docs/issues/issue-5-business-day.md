# 영업일 유예: T+2를 달력일 → 영업일 기준으로

## 목표
#4의 달력일 T+2 유예를, 주말·공휴일을 건너뛰는 영업일 기준으로 바꾼다.

## 범위
- 공휴일 소스 확보(휴일 목록을 어디서 얻을지 결정 — 이게 이 이슈의 핵심 난점).
- 유예 계산을 달력일 → 영업일로 교체.
- 데이터로 두는 원칙 유지: 휴일을 코드 상수가 아니라 조회 가능한 데이터로.

## 완료 기준
- [ ] 주말·공휴일을 건너뛰어 유예 만료일 계산
- [ ] 변이 테스트: 금/토/일·공휴일 낀 경계
- [ ] 로직을 뒤집으면 해당 테스트만 red
